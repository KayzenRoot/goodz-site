# Requirements
- R01: Site público responsivo, identidade grafite/dourado/creme e logos aprovados.
- R02: Distinguir visual e semanticamente GOODZ Pastelaria e GOODZ Dogueria.
- R03: Admin autenticado deve alterar logos, hero e banners por upload validado.
- R04: Admin deve criar, atualizar, ocultar e excluir produtos por submarca, com imagens.
- R05: Links iFood/99Food/Instagram/TikTok/WhatsApp editáveis; sem links fictícios.
- R06: Persistência em SQLite e volume de uploads.
- R07: Segurança mínima: senha hash forte, sessão HTTP-only, CSRF, validação de imagens, rate limit, sem default password.
- R08: Testes API, CRUD, autenticação, upload; interface verificável em desktop e mobile.
