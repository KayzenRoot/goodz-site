# Definition of Done
- [ ] Site em desktop/mobile usa marca aprovada e diferencia submarcas
- [ ] Admin faz login, edita textos, imagens, produtos e links
- [ ] Dados persistem após reinício
- [ ] Suite automatizada passa e screenshots desktop/mobile revisadas
- [ ] Documentação corresponde ao código
- [ ] Deploy HTTPS com domínio, backup e smoke-test validados
NOTA: enquanto deploy externo não ocorrer, versão LOCAL_VALIDATED, não RELEASE_COMPLETE.
